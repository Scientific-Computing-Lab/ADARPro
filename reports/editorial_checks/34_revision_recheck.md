| Anchor | From Hebrew | From German | From Japanese | From Spanish |
|---|---|---|---|---|
| Tissue variation | Editing varies between tissues at a fixed genomic identity. | Different tissues can edit the same position differently. | The position stays fixed; its editing varies by tissue. | Tissue variation concerns editing, not a different genomic position. |
| Information-source question | Gains from added measurements and better use of present RNA information are compared against one reference. | The comparison separates added-assay gains from better input use, using a common reference. | Existing RNA information and additional biological measurements provide two separately tested routes to improvement. | Both extra measurements and improved input use are tested relative to the same baseline. |
| Contextual null | The tested coarse measurements do not consistently improve site prediction; biological roles remain possible. | No consistent site-level increment follows from the tested assays, without excluding regulatory biology. | The negative result concerns site prediction from these measurements, not biological absence. | Failure to improve site-level predictions consistently does not negate biological function. |

| Matched-site comparator | Separate analyses do not clearly beat predictions using tissue identity only. | The reference uses tissue identity alone, with no clear improvement from added information. | Separate comparisons show no clear improvement over the tissue-identity baseline. | Tissue-identity-only references are not clearly outperformed. |

| Local retention | Retaining local information is tested against whole-duplex averaging, without assuming the target marker is absent. | The question is whether preserving local information helps beyond pooling, not whether the graph contains a target label. | The experiment tests additional predictive value from local retention in an already target-marked graph. | Local retention is compared with global averaging, without assuming missing target identification. |
| Confounded variants | Feature and architecture changes occur together and are distinguished from controlled completed and untested branches. | Some variants change both input features and architecture, so they belong in a different evidence class from controlled or unrun tests. | Simultaneous feature/architecture changes are kept separate from completed matched comparisons and untested options. | Changing both features and architecture is not an isolated capacity test or an unperformed experiment. |

The revised subjects, comparators, metric directions, and inferential boundaries
survive these routes. This is an editorial judgment, not an independent reader
experiment or a claim that all possible translations are equivalent.
