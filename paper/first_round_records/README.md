# First-round manuscript records

These files describe the first-round manuscript (PNAS draft, audits dated 2026-09-10), not the current paper. They
are kept for provenance only, and nothing in the build reads them.

- `claim_traceability.csv`: the first round's map from principal claims to campaign artifacts. Every number in the
  current paper is traced instead by `../numerical_claim_ledger.csv` (written by `scripts/build_paper_claim_ledger.py`).
- `EPISTEMIC_CLAIM_AUDIT.md` and `TERMINOLOGY_AUDIT.md`: the first round's claim-boundary and vocabulary audits.
- `title_candidates.md`: the first round's title options.
